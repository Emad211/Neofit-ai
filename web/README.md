# NeoFit Web — Stage 1

This directory contains the active Persian-first web product prototype.

## Current scope

- Next.js App Router
- strict TypeScript
- `lang="fa"` and `dir="rtl"` at the root
- mobile-first Today dashboard
- IFKB-shaped Persian food search
- portion-based meal logging sheet
- weekly plan preview
- Settings mock for language, theme and AvalAI key states
- loading, empty, error and offline design states

There is intentionally no Supabase, authentication, live AI call, full PWA service worker or production synchronization in Stage 1.

## Run

```bash
cd web
npm install
npm run typecheck
npm run build
npm run dev
```

## Source boundary

Fixture nutrition values are copied from the existing versioned Iranian starter catalog and are used only to validate UX shape. The web prototype must not accept nutrition values generated by AvalAI or Vision.

## Required review widths

- 360 px
- 390 px
- 412 px

Stage 1 is not complete until the product owner reviews the five critical flows and accepts the UX direction.
